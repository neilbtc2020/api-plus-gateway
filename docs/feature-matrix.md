# 功能矩阵

本文档用于快速了解 API Plus Gateway 的能力覆盖范围。展示仓库不包含完整源码，具体能力以实际交付版本和部署配置为准。

## 网关与协议

| 能力 | 说明 |
| --- | --- |
| OpenAI-compatible | 面向主流 SDK 和工具链的兼容入口 |
| OpenAI Responses | 适配 Responses 协议形态，便于新模型能力接入 |
| Claude Messages | 支持 Claude Messages 风格的请求与转换 |
| Google Gemini | 支持 Gemini 聊天协议接入与转换 |
| Rerank | 支持 Cohere、Jina 等重排序模型接入方向 |
| 图像/音频/Realtime | 面向多模态和实时能力的统一网关入口 |
| 任务类接口 | 可扩展 Midjourney、Suno 等异步任务平台 |

## 渠道与稳定性

| 能力 | 说明 |
| --- | --- |
| 渠道权重 | 多渠道按权重分发请求 |
| 失败重试 | 失败后自动尝试可用渠道，降低单点波动影响 |
| 渠道测试 | 管理员可测试渠道连通性和模型能力 |
| 模型可用性 | 聚合模型可用性状态，辅助用户和管理员判断 |
| 渠道亲和缓存 | 在适合场景中保持用户/模型与渠道的短期亲和 |
| 错误日志 | 保留异常上下文，方便排查供应商、模型或配置问题 |

## 商业化与计费

| 能力 | 说明 |
| --- | --- |
| 用户额度 | 支持用户余额/额度管理和消耗记录 |
| 在线充值 | 适配 Stripe、易支付等支付方向 |
| 订阅套餐 | 支持套餐配置、用户绑定、周期重置等运营能力 |
| 余额事件 | 记录签到、充值、订阅、后台调整等额度变化来源 |
| 返佣 | 支持邀请关系、返佣日志、统计和后台结算方向 |
| 账单查询 | 面向用户和管理员提供消费、充值、订阅相关查询 |

## 用户与安全

| 能力 | 说明 |
| --- | --- |
| OAuth 登录 | 支持 GitHub、Discord、LinuxDO、OIDC 等登录方式 |
| Telegram 登录 | 支持 Telegram 授权登录/绑定方向 |
| Passkey | 支持无密码登录扩展方向 |
| 二次验证 | 支持 TOTP 等安全加固方向 |
| 令牌管理 | 支持用户令牌、额度限制、模型限制和分组权限 |
| 权限分层 | 管理员、用户、Root 配置等角色边界 |

## 管理后台

| 能力 | 说明 |
| --- | --- |
| 渠道管理 | 增删改查渠道、测试渠道、维护多 key 或供应商配置 |
| 模型管理 | 模型元信息、模型倍率、分组可用性和展示控制 |
| 用户管理 | 用户额度、权限、OAuth 绑定、订阅与账单查询 |
| 运营设置 | 站点配置、充值配置、订阅配置、登录配置 |
| 统计看板 | 面向收入、消耗、渠道、模型和用户行为的运营分析方向 |

## Playground

| 能力 | 说明 |
| --- | --- |
| 用户令牌接管 | 用户可在 Playground 中选择自己的令牌进行真实调用 |
| 真实协议直连 | 尽量贴近真实 API 请求链路，便于测试与排查 |
| 调用反馈 | 展示请求结果、错误信息和模型输出 |
