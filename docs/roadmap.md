# 路线图

以下路线图用于展示 API Plus Gateway 适合继续打磨的方向，具体优先级以真实业务反馈为准。

## 近期重点

| 方向 | 目标 |
| --- | --- |
| 商业闭环稳定性 | 强化充值、订阅、返佣、余额事件和对账链路 |
| 渠道可用性 | 完善模型可用性聚合、异常识别和后台展示 |
| 用户体验 | 优化 Playground、令牌管理、账单查询和套餐展示 |
| 管理效率 | 提升后台过滤、批量操作、日志排查和统计能力 |

## 中期方向

| 方向 | 目标 |
| --- | --- |
| 成本优化 | 围绕模型价格、渠道倍率、缓存计费和供应商成本做精细化策略 |
| 风控能力 | 加强异常请求、滥用、额度套利、支付异常和渠道密钥风险控制 |
| 企业化能力 | 增加组织、团队、项目、子账号和审计日志方向 |
| 文档体系 | 补齐部署手册、二开指南、API 示例和运维 SOP |

## 长期方向

| 方向 | 目标 |
| --- | --- |
| 多租户运营 | 支持更复杂的代理商、团队和租户隔离场景 |
| 智能调度 | 基于成本、延迟、错误率、额度和供应商状态自动选路 |
| 插件化适配 | 更低成本接入新的模型供应商、支付方式和登录方式 |
| 可观测性 | 将请求链路、计费链路、渠道状态和支付状态打通成完整运营视图 |
